# Proposed Code Availability statement

Code and small archived result tables supporting this study will be deposited in a public repository after final rights and release approval. The release candidate preserves the implementation used for data processing, feature construction, nested leave-one-landscape-out model comparison, sensitivity analyses and geological-history feasibility screening, together with frozen configurations and manuscript-to-code traceability. Raw and processed geospatial datasets will not be redistributed because they combine sources with provider-specific attribution and redistribution terms; access routes and licences are documented in the repository. The package verifies reported values against archived outputs but does not claim an independent end-to-end rerun or untouched external validation. Add the assigned repository URL to this statement only after repository creation is separately approved.
